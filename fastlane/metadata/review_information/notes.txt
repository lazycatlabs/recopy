ReCopy is a menu bar clipboard history. Open it with Shift-Command-V or from the menu bar icon. On first launch it asks for a folder to store the history in; any folder works.

ReCopy does not request or use the Accessibility permission. Picking an entry puts it on the clipboard; the user pastes it with Command-V.

No account or sign-in is needed. The only network use is fetching the title, icon and preview image of links the user copied.
